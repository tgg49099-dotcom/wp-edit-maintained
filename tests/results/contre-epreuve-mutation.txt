RED COUNTER-PROOF - WP Edit 4.0.4
This file proves that the test harness really exercises the patched lines:
the SAME test, in the SAME environment, is run twice on the SAME patched
code - once with the compatibility fix removed (it must go RED), once with
the fix put back (it must go GREEN).
==============================================================================

Date        : 2026-11-12
WordPress   : 6.8.12 and 7.1.4 (real installations, SQLite)
PHP         : 8.3.29 and 8.5.8
Case used   : WordPress 7.1.4 / PHP 8.3.29
Harness     : tests/run-case.sh  (the harness published in this repository)

------------------------------------------------------------------------------
1. THE MUTATION
------------------------------------------------------------------------------
Only the compatibility fix is touched. Not one byte of anything else.

File      : wp-edit/includes/functions.php
Before    : the patched file published in this repository
            md5 8193113bfab637c23336be6de8eca5a3

  broken : if($plugin_options_global['disable_admin_links'] != 1) {

            md5 c58f44ca2e78ca82b9f2961818c8f071

The mutation is applied by an exact string replacement that REFUSES to write
if the pattern is not found exactly once, so a mutation that missed its
target could not be mistaken for a proof.
